## HTC Sense Bokeh Live Wallpaper — Ocean Blue

- **Package:** `com.htc.android.wallpaper`
- **versionCode:** `70`
- **versionName:** `1.01-ocean-blue`
- **minSdk:** 24 · **targetSdk:** 36

Smooth ocean gradient with Sense-style bokeh bubbles (Java/OpenGL port for 64-bit devices).

### Install

1. Download **`HTC-Sense-LiveWallpaper-ocean-blue.apk`** below.
2. Install, then choose **HTC Sense** in **Live wallpapers**.
3. If the home screen still shows an old theme, switch wallpaper once and select **HTC Sense** again.

For crimson/red or the rainbow archive build, see other releases in this repo.
