### Install

1. Download **`HTC-Sense-LiveWallpaper-android36.apk`** below.
2. Uninstall any newer **`com.htc.android.wallpaper`** build if install is blocked (lower versionCode).
3. Select **HTC Sense** in **Live wallpapers**.
