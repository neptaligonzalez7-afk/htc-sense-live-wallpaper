## HTC Sense Bokeh Live Wallpaper — Crimson

- **Package:** `com.htc.android.wallpaper`
- **versionCode:** `69`
- **versionName:** `1.02-crimson`
- **minSdk:** 24 · **targetSdk:** 36

Red Sense-style bokeh gradient (`#810020` / `#900A22` / `#A41726`) with the same bubble field as ocean blue.

### Install

1. Download **`HTC-Sense-LiveWallpaper-crimson.apk`** below.
2. If you already have **ocean blue** (versionCode **70**) installed, **uninstall** the live wallpaper app first — Android blocks downgrades on the same package.
3. Install, then pick **HTC Sense** in **Live wallpapers**.

See **ocean blue** release for the recommended default blue variant.
