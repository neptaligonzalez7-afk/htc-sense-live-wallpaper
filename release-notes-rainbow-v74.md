## HTC Sense Bokeh Live Wallpaper — Rainbow

- **Package:** `com.htc.android.wallpaper`
- **versionCode:** `74`
- **versionName:** `1.04-rainbow`
- **minSdk:** 24 · **targetSdk:** 36

Classic **multi-color Sense** look matched to the original Bokeh thumbnail: yellow/orange top, green and lavender mid-tones, deep blue bottom. Background uses a blurred reference color field; live white bokeh bubbles render on top (same density as ocean/crimson builds).

### Install

1. Download **`HTC-Sense-LiveWallpaper-android36.apk`** below.
2. If install is blocked, uninstall any other **HTC Sense** wallpaper app on the phone first (only one color can be installed at a time).
3. Select **HTC Sense** in **Live wallpapers**.

### Changes from v54

- Correct rainbow background colors (texture-based wash, not the old simplified gradient).
- More bubbles aligned with ocean/crimson builds.
- Orientation fix so the color layout matches classic Sense (warm top, blue bottom).
