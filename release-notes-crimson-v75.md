## HTC Sense Bokeh Live Wallpaper — Crimson

- **Package:** `com.htc.android.wallpaper`
- **versionCode:** `75`
- **versionName:** `1.03-crimson`
- **minSdk:** 24 · **targetSdk:** 36

Red Sense-style bokeh gradient with the same bubble field as ocean blue and rainbow.

### Install

1. Download **`HTC-Sense-LiveWallpaper-crimson.apk`** below.
2. Install over **rainbow (v74)** or **ocean blue (v70)** without uninstalling (this build uses a higher versionCode).
3. Pick **HTC Sense** in **Live wallpapers** (re-select if colors do not update).

### Why v75?

Android refuses **downgrades** on the same package. The previous crimson release was **versionCode 69**, so it could not install while **rainbow v74** or **ocean v70** was on the phone. Use this release instead of v69.
